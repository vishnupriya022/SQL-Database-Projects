# SQL-Projects-Portfolio

This repository contains SQL projects demonstrating database creation, querying, and reporting using Snowflake SQL and standard SQL.

## Projects

1. [Employee Management System] (https://github.com/vishnupriya022/sql-employee-management.git)

   A simple Employee Management System built using Snowflake SQL.This project demonstrates database design, SQL querying, reporting, and GitHub version control.

2. [Student Management System] (https://github.com/vishnupriya022/StudentManagementSQL.git)

   This project demonstrates basic SQL operations such as creating tables, inserting data, running queries, updating, and deleting records in a Student Management database.
